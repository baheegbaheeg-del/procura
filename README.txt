صِلَة — نسخة تشغيلية لإدارة المشتريات والتوريد
=================================================

صِلَة منصة B2B تربط العملاء بالموردين لإدارة طلبات الشراء، عروض الأسعار،
المقارنة، أوامر الشراء، ومتابعة التوريد.

الحسابات والدخول
----------------

- تسجيل الدخول منفصل تمامًا عن إنشاء الحساب.
- إنشاء الحساب متاح للعميل أو المورد فقط، والدخول يتم فورًا بدون رسالة تأكيد بريد.
- حسابات الإدارة لا تُنشأ ذاتيًا؛ ينشئها مالك النظام ويستخدمها للمراجعة والاعتماد.
- كل حساب جديد يبدأ بملف شركة فارغ، ثم يضيف بيانات الاتصال والسجل التجاري
  والبطاقة الضريبية وبيانات المفوض بالتوقيع.
- تظهر مستندات التحقق للطرف الآخر فقط بعد اعتماد الإدارة.

البيانات
--------

- لا توجد حسابات أو طلبات أو عروض أو مرفقات تجريبية في الواجهة.
- بعد تسجيل الدخول، تظهر البيانات الحقيقية المحفوظة في مشروع Supabase فقط.
- إذا لم يوجد طلب أو عرض بعد، تظهر حالة فارغة واضحة بدل بيانات افتراضية.
- المرفقات تُحفظ في التخزين الخاص بـ Supabase ويمكن فتحها أو تنزيلها للمستخدم
  المخوّل.

البوابات
--------

1) بوابة العميل / المشتريات
   - إنشاء طلب شراء ببنود يدوية، أو مرفق فقط، أو الاثنين معًا.
   - استقبال عروض تفصيلية ومقارنتها وإصدار أوامر شراء.

2) بوابة المورد
   - تجهيز ملف الشركة والتوثيق.
   - استعراض الطلبات وإرسال عرض سعر يشمل إجمالي البنود، الخصم، الضريبة،
     النقل، الرسوم، والإجمالي النهائي.
   - متابعة حالة التوريد حتى تأكيد الاستلام.

3) لوحة الإدارة
   - اعتماد الحسابات ومراجعة المستندات.
   - متابعة الطلبات والعروض والأوامر والائتمان والنزاعات.

التشغيل والنشر
--------------

1. لا تشغّل `supabase/schema.sql` مرة أخرى؛ قاعدة البيانات موجودة بالفعل.
2. أبقِ `Confirm email` مغلقًا من:
   Authentication → Sign In / Providers → Email.
3. انشر الملفات المحدثة إلى فرع `main` في مستودع GitHub المرتبط بمشروع Vercel.
4. بعد اكتمال Vercel، افتح الموقع وسجّل حساب عميل أو مورد جديد للتجربة.

الملفات الأساسية
----------------

- `index.html`: الواجهة.
- `app.js`: منطق البوابات ودورة الشراء وتدفق الدخول.
- `supabase-client.js`: اتصال Supabase والحسابات والبيانات والمرفقات.
- `supabase/schema.sql`: مخطط قاعدة البيانات والصلاحيات الحالي.
- `supabase-config.js`: رابط مشروع Supabase والمفتاح العام فقط.
