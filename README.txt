صِلَة — النموذج النهائي لربط العملاء والموردين
==============================================

هذه نسخة عرض تشغيلية متكاملة لبدء التواصل مع الموردين والعملاء.
تتضمن ثلاث بوابات مترابطة:

1) بوابة العميل / المشتريات
   - إنشاء طلب شراء RFQ (آر إف كيو: طلب عرض سعر).
   - إضافة بنود وكميات ووحدات ومواصفات ومرفقات.
   - استقبال عروض تفصيلية ومقارنتها بندًا ببند.
   - اختيار مورد واحد أو تقسيم البنود بين عدة موردين.
   - إصدار أوامر شراء ومتابعة التوريد وتأكيد الاستلام.
   - طلب حد ائتماني وتقييم المورد بعد التنفيذ.

2) بوابة المورد
   - ملف شركة ومعلومات اتصال وفئات وماركات وشروط دفع ومدة توريد.
   - توثيق السجل التجاري والبطاقة الضريبية والمفوض بالتوقيع.
   - استعراض الطلبات المفتوحة وتقديم أو تحديث عرض تفصيلي لكل بند.
   - تضمين سعر الوحدة والتوفر والماركة وبلد المنشأ والضمان والخصم والنقل وشروط الدفع.
   - تأكيد أمر التوريد وتحديث حالته: تجهيز → خرج للتوريد → تم التسليم.
   - تقييم العميل بعد اكتمال العملية.

3) لوحة إدارة صِلَة
   - مراجعة واعتماد أو رفض حسابات العملاء والموردين.
   - متابعة جميع الطلبات والعروض وأوامر الشراء.
   - إدارة طلبات الائتمان والتقييد الائتماني.
   - متابعة النزاعات وسجل العمليات.
   - عرض التقييمات ومؤشرات الثقة التشغيلية والمالية بشكل منفصل.

نموذج العمل الثابت
------------------

- صِلَة منصة تنظيم مشتريات ووساطة B2B، وليست بائعًا أو مخزنًا للبضاعة.
- المورد يفوتر العميل، والعميل يسدد للمورد مباشرة.
- صِلَة تفوتر خدمتها بصورة منفصلة.
- عرض المورد المؤسس: التسجيل وتجهيز الحساب مجانًا، أول 3 مبيعات ناجحة بلا رسوم، وأي رسوم لاحقة تظهر قبل تقديم العرض.
- سوق الإطلاق: القاهرة الكبرى، مع تركيز أولي على مواسير ووصلات PPR / PVC / UPVC.

طريقة تجربة النظام
------------------

افتح index.html في المتصفح ثم اختر أحد الحسابات التجريبية:

- عميل تجريبي: شركة النور للتشطيبات.
- مورد تجريبي: المستقبل للتوريدات.
- إدارة تجريبية: إدارة صِلَة.

يمكن أيضًا إنشاء أي بريد تجريبي جديد واختيار نوع الحساب.

لشرح الدورة لمورد:

1. افتح "تحميل العرض التجريبي" ثم "مورد تجريبي".
2. اعرض "ملف المورد والتوثيق" ثم "طلبات متاحة".
3. افتح طلبًا وقدّم أو حدّث عرضًا تفصيليًا.
4. انتقل إلى "عميل تجريبي" وافتح "العروض والمقارنة".
5. اختر المورد لكل بند وأصدر أوامر الشراء.
6. ارجع إلى المورد لتحديث حالة أمر التوريد.

تنبيه مهم قبل الاستخدام مع شركات حقيقية
---------------------------------------

هذه النسخة تحفظ البيانات داخل المتصفح (Local Storage / لوكال ستورِج).
لذلك تعمل الدورة كاملة على نفس الجهاز والمتصفح، وهي ممتازة للعرض الأولي
والتجارب وجمع ملاحظات الموردين.

قبل تشغيلها فعليًا بين شركات وموردين على أجهزة مختلفة، يلزم ربطها بقاعدة
بيانات سحابية، دخول حقيقي، صلاحيات، تخزين ملفات آمن، ورسائل/تنبيهات.

محتويات الحزمة
--------------

- index.html : الواجهة الرئيسية.
- app.js : منطق البوابات ودورة الشراء.
- vercel.json : إعداد رفع Static على Vercel.
- دليل_التواصل_مع_الموردين.txt : نص عملي مختصر لبدء المكالمات.
